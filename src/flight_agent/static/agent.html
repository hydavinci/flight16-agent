目录使用说明

位置只说明资源所在主机与登记方式，不选择任务类型或注入判据。 知识问答与显式输入能力不需要目录。

输出根目录是 Agent 所在机器的绝对目录，不是远程 Worker 路径。

每个任务新建独立子目录，不覆盖历史成果。 可在聊天中写“输出目录：/绝对路径”；修改或清空目录栏后，随任务需求发送才会生效。
